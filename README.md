
# 📥 Instagram Download Manager [![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen)](https://be-like-akay.github.io/Instagram-Download-Manager/)

A modern bulk download manager for Instagram content with beautiful UI and parallel downloading capabilities.

Screenshot![[Screenshot]
](https://github.com/BE-LIKE-AKAY/Instagram-Download-Manager/blob/main/SS.png)
## ✨ Features

- 🎨 **Stunning Neon UI** with smooth animations
- ⚡ **Parallel Downloads** (configurable concurrency)
- 📊 **Real-time Progress Tracking**
- 📱 **Fully Responsive** (Desktop/Tablet/Mobile)
- 📜 **Interactive Download Logs**
- 🎉 **Confetti Celebration** on completion
- 🚦 **Smart Error Handling**
- 📁 **Drag & Drop** URL file upload
- 📈 **Live Statistics** Dashboard

## 🚀 Quick Start

1. Clone repo:
```bash
git clone https://github.com/be-like-akay/Instagram-Download-Manager.git
cd Instagram-Download-Manager
python3 -m http.server 800
```
🛠 Usage
Prepare urls.txt file with Instagram URLs (one per line)
- Open web interface
- Upload your URL file
- Set parallel downloads (default: 4)
- Click "Launch Download"
- Monitor real-time progress
